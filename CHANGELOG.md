# Changelog

## chuchi 0.1.7

-   **Breaking:** cookies default to `Path=/`, remove them with the path they
    were set with (`remove(name, { path })`).
-   Fixes for cookies, `SsrCache`, scroll restoration, hash links and `//`
    paths in the router.

## chuchi-utils 0.1.7

-   Fixes for `range`, `searchScore` and `SlotArray.remove`.

## chuchi-core 0.1.6

-   Better errors for non-json responses, first JSR release.

## chuchi-legacy 1.1.1

-   `inViewY` fix, first JSR release.
